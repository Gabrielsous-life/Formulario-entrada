# Formulário de Inscrição

Formulário de inscrição responsivo feito com HTML, CSS e JavaScript puro.

**[Ver online](https://gabrielsous-life.github.io/Formulario-entrada/)**

## Funcionalidades

- Campos de nome, e-mail, senha e confirmação de senha com validação nativa do HTML5
- Botão para mostrar/ocultar a senha
- Seleção de turno (radio) e disciplinas de interesse (checkbox)
- Campo de mensagem livre e botões de enviar e limpar
- Layout centralizado em cartão, com fundo em gradiente

## Tecnologias

- HTML5
- CSS3 (Flexbox)
- JavaScript

## Como rodar

Não precisa de instalação: basta abrir o `index.html` no navegador.

```bash
git clone https://github.com/Gabrielsous-life/Formulario-entrada.git
```

## Estrutura

```
index.html     # estrutura do formulário e script de mostrar/ocultar senha
style.css      # estilos
eye*.svg       # ícones do botão de senha
```
